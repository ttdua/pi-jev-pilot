## REMOVED Requirements

### Requirement: When assessment runs

**Reason**: Tool assessment is removed; a worker gets exactly the tool set the executor resolves from its agent definition, with no Jev adjustment; a child that needs more asks its parent with `ask_parent`.

**Migration**: None needed. A `tools` section in `config.json` and a boolean `switches.tools` in `state.json` are accepted and ignored (see `config-file`, `state-file`); old ledger lines with `toolsScored`, `toolsFlagged` or `toolsGranted` still validate (see `decision-ledger`).
